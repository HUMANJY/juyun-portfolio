건설현장 CCTV 객체 검출 모델 개선

2026.07 – 08 · 2人 팀 · 담당: 데이터 신뢰성 · 통제 실험 · 반자동 라벨링 (협업자: 데이터 확장 · 배포)

1. 보고된 지표부터 의심했습니다

person Recall이 35%로 보고돼 있었는데 현장 영상을 볼 때마다 체감과 맞지 않았습니다. 모델을 손대는 대신 데이터를 먼저 감사했습니다. 파일명으로 비교하면 학습셋과 검증셋의 겹침은 0이었지만 md5로 대조하니 같은 영상이 다른 이름으로 여러 번 들어가 있었습니다. 학습 어댑터도 프레임 목록을 인덱스로 80/20 자르고 있었고, 파일명이 콘텐츠 해시라 순서가 무작위여서 검증 영상의 88%가 학습에도 존재했습니다. 실제 Recall은 5%였습니다.

  • 영상 단위로 묶어 자르는 분할 어댑터를 별도 파일로 작성해 기존 모델에 영향 없이 적용
  • 조기종료 정상화 → 학습 시간 9.1h → 2.3h
  • 체크포인트 선택 오류로 0%였던 RMC Recall 0% → 47.8% 복구
  • 중복 정제로 학습 박스 42,699 → 29,783(−30%), 검증 238 → 140프레임

2. 변수를 하나씩만 바꿔 7개 모델을 비교했습니다

3. 병목은 데이터 부족이 아니라 입력 해상도였습니다

놓친 박스를 conf 0.001로 재추론해 저신뢰 / 클래스 오분류 / 박스 부정확 / 완전 미검출로 나눴더니 84%가 완전 미검출이었습니다. 임계값 튜닝으로는 얻을 수 없다는 뜻이라, 잔여 오류를 객체 크기 구간으로 다시 갈랐습니다. 같은 클래스인데 크기에서만 성능이 갈렸습니다.

4. 손 라벨 50장을 학습셋 23,475장으로 만들었습니다

신규 현장 데이터에는 손 라벨 50프레임밖에 없었습니다. 이걸 앵커로 SAM2를 25개 영상에 전파해 17,447프레임을 만들었지만 그대로 쓰면 학습을 점령합니다. 라벨 시그니처 중복제거와 기존 데이터와의 시간 밀도 정합(2.1샘플/초)을 거쳐 556프레임으로 줄이고, 박스 드리프트와 독립 모델 IoU 교차검증으로 품질을 확인했습니다.

5. 외부 데이터로 죽어 있던 클래스를 살렸습니다

학습 데이터가 영상 1개·20박스뿐이라 네 번의 실험 내내 Recall 0%였던 excavator를 위해 AI Hub 공개 데이터를 편입했습니다. 원본 90,258장 중 인접 프레임의 47%가 해밍거리 2 이하로 사실상 같은 이미지라, 지각해시 기반 다양성 선별로 3%만(2,874장) 남겼습니다.

YOLO LIFE — 엘리베이터 CCTV 자동 라벨링 툴

2026.03 – 06 · 2人 팀 · 담당: 백엔드 · 프론트엔드 · 인프라 · Predictor Adapter (협업자: AI 파이프라인 · 파인튜닝 · SAM2 추적)

배경

약 15,000장 규모의 엘리베이터 영상을 CVAT으로 전량 수동 라벨링하던 구조라 데이터 확보 속도가 모델 개선 속도를 따라가지 못했습니다. AI가 1차로 그리고 사람은 검수·교정만 하는 웹 도구를 직접 만들어 사내 내부망에 배포했습니다. 대상 클래스는 person / dog / robot / wheelchair 네 가지입니다.

구현에서 맡은 부분

  • 자동 라벨링 1-콜 엔드포인트 — list/delete/create로 수십 회 오가던 요청을 단일 트랜잭션으로 묶어 GPU를 끊김 없이 사용
  • Predictor Adapter — 환경변수에 따라 mock / COCO pretrained / 자체 모델을 자동 선택. 모델이 나오기 전에 백엔드·프론트를 먼저 완성
  • 좌표 계약 분리 — AI 모듈은 픽셀 좌표를 반환하고, 백엔드가 0~1 정규화와 경계 클리핑을 책임
  • 검수 UI — Konva 캔버스 폴리곤 오버레이, Ctrl+1~4 즉시 클래스 교정, 기대 객체 수 검증, 저신뢰도 Issues 큐
  • ROI 서버 저장 — 엘리베이터 거울 반사 구역을 미리 제외해 자동 라벨링 단계에서 오탐 차단
  • Export 5포맷 — YOLO Seg/Detect · COCO · Pascal VOC · CSV zip 스트리밍
  • 협업 — 인메모리 Presence(heartbeat)와 이미지 소프트 잠금으로 라벨러 동시 작업 지원

모델 선정

SAM3의 텍스트·컨셉 프롬프트 탐지는 YOLO가 BBox를 만들어 주는 이 구조에서 쓰이지 않습니다. SAM2로 바꿔 폴리곤 품질은 같게 두고 자원만 줄였습니다. YOLO도 처음엔 YOLO11s-seg를 파인튜닝(V1~V5)해 실험 최고 Mask mAP50 0.921을 얻었지만, 연속 파인튜닝에서 mAP50-95가 0.785 → 0.772로 누적 하락하고 단일 도메인에만 맞춰졌습니다. 안전관제·불꽃 탐지 확장을 감안해 운영 모델은 yolo11m-seg COCO pretrained + sam2_l로 정했습니다.
